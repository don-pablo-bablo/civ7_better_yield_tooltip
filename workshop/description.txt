The game says a tile makes 9 Science. This mod says why: base tile, adjacency, each building's own yield, Great Works, policies, pantheon, civ and leader abilities, specialists and appeal, each with its amount.

[h2]How to use it[/h2]
[olist]
[*]Hover a tile.
[*]Press [b]K[/b] to lock the tooltip.
[*]Hover the row of yield icons at the bottom of the tooltip.
[/olist]

The breakdown opens beside it: the tile first, then each building on it. Every number comes from the game. The mod only works out which source each one belongs to.

When the game gives an amount with no source, the mod matches it against your bonuses. If one bonus fits exactly, it is named. If several could fit, the line is dimmed and lists them, for example "+2 Science from Literature OR Philosopher's Circle". Anything left over is shown as [b]Unattributed[/b].

[h2]Compatibility[/h2]
[list]
[*]The mod only changes the interface. You can add it to a game in progress or remove it without breaking the save.
[*]It works by replacing the tooltip's yield bar. Another mod that replaces the yield bar will clash with it, and only one of them will show.
[/list]
